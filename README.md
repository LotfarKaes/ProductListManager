# Advanced Inventory System

Welcome to the Level 4 Inventory Project! This is a smart app that helps you manage items like a real store. 

---

## What It Can Do

* **Easy Menu:** Pick what you want to do from a simple list of numbers.
* **No Twins:** The app stops you from adding the same product twice. If it already exists, it shows a warning!
* **Smart Search:** Find products quickly by typing their name or product number.
* **Delete Items:** Remove products you no longer need with one easy step.
* **Fun Stats:** See helpful numbers like your total products, highest number, lowest number, and average.
* **Save Your Work:** Automatically saves your products to a file so you never lose them.

## How to Run It

1. Open the project folder in **Visual Studio**.
2. Run the solution file.
3. Follow the menu on your screen to add, search, or view your items!
